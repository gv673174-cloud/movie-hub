# Movie-Hub
<h1>🎬 Movie Explorer Web App</h1>
  <p>
    A fully responsive dynamic movie website built with both frontend and backend technologies. Users can browse movies, search for movies, and explore different movie categories.
  </p>

  <h2>🚀 Features</h2>
  <ul>
    <li>🎥 Dynamic movie website</li>
    <li>🔍 Movie search functionality</li>
    <li>📂 Movie categories such as Bollywood and Hollywood</li>
    <li>🖼️ Responsive movie slider</li>
    <li>🗄️ MySQL database integration</li>
    <li>🔐 Backend/admin functionality</li>
    <li>🎨 Clean and user-friendly interface</li>
    <li>⚡ Fast and interactive UI</li>
  </ul>

  <h2>🛠️ Tech Stack</h2>
  <ul>
    <li><b>Frontend:</b> HTML, CSS, JavaScript</li>
    <li><b>Tools:</b> VS Code, Git, GitHub</li>
  </ul>
  <h2>⚙️ Installation & Setup</h2>
  <ol>
    <li>Clone the repository</li>
    <code>git clone https://github.com/your-username/movie-app.git</code>

    <li>Navigate to the project folder</li>
    <code>cd movie-app</code>

    <li>Open <b>movie.html</b> in your browser</li>
  </ol>
